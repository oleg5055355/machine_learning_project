# Machine Learning Project

**TU Dublin | BSc (Hons) Computing with Machine Learning & AI**

**Third-Year Group Project | Artificial Intelligence: Theory to Practice (COMPH3004)**

## Project Overview

A supervised machine learning project focused on predicting vehicle loan defaults using traditional machine learning and deep learning models.

The project includes exploratory data analysis, data preprocessing, feature engineering, model development, hyperparameter tuning, and performance evaluation.

## Dataset

- **Dataset:** NBFI Vehicle Loan Repayment Dataset
- **Source:** https://huggingface.co/datasets/mstz/nbfi
- **Records:** 8,308
- **Input features:** 35
- **Target:** Binary classification (loan default)
- **Class imbalance:** Approximately 7% defaults

## Machine Learning Models

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. k-Nearest Neighbours
5. Naive Bayes
6. Linear Support Vector Machine
7. Histogram Gradient Boosting
8. XGBoost
9. LightGBM
10. CatBoost

## Deep Learning Models

11. Multilayer Perceptron (MLP)
12. MLP with Batch Normalisation and Dropout
13. Residual MLP
14. TabNet
15. FT-Transformer

## Technologies

Python, Jupyter Notebook, NumPy, pandas, Matplotlib, scikit-learn, PyTorch, XGBoost, LightGBM, CatBoost, TabNet.

## Evaluation

- Train / validation / test splitting
- Stratified 5-fold cross-validation
- Hyperparameter tuning
- Precision–Recall AUC (Average Precision)
- Balanced Accuracy
- Macro F1
- Confusion matrices
